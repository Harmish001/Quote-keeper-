# QuoteKeeper

Save quotes from any app on your phone in ~2 taps.

## Get the APK
1. Create a new GitHub repo, push this folder to `main`:
   ```
   git init && git add . && git commit -m "QuoteKeeper"
   git branch -M main
   git remote add origin https://github.com/<you>/QuoteKeeper.git
   git push -u origin main
   ```
2. Open the repo → **Actions** tab → wait for "Build APK" to go green (~3–5 min).
3. Open the repo's **Releases** page on your phone → download `app-debug.apk` → install
   (allow "install unknown apps" for your browser when asked).

## Use it
- In your PDF viewer / browser / reader: long-press and select text → tap **⋮ / More** in the
  selection toolbar → **Save Quote** → check the book (last one is prefilled) → Save.
- Apps that hide that menu: select text → Share → **Save Quote**.
- Open QuoteKeeper to browse by book, search, edit, copy, delete, or export (Markdown / JSON).
